# SlimHuisTech Child Theme

Custom WordPress child theme developed for the SlimHuisTech project.

## Purpose
This repository contains a Gutenberg-first WordPress child theme.
The goal of this project is to practice theme development, block styles,
and reusable block patterns using modern WordPress standards.

## Tech stack
- WordPress (Block Theme / Gutenberg)
- Child theme based on Twenty Twenty-Five
- PHP (theme setup)
- CSS (custom styles)
- JavaScript (lightweight interactions)
- Git (version control)

## Local development
This theme is developed locally using **Local WP**.

To use the theme locally:
1. Install WordPress using Local WP
2. Install and activate the parent theme: Twenty Twenty-Five
3. Copy the `sht-child` folder into:
   `wp-content/themes/`
4. Activate **SlimHuisTech Child** from the WordPress admin
